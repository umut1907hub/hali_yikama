# Halı Yıkama Atölyesi

Tarayıcıda oynanan, ASMR odaklı bir halı ve paspas yıkama simülasyonu. Tek bir HTML dosyası; Canvas, CSS ve saf JavaScript ile yazıldı. Görseller algoritmik çiziliyor, sesler Web Audio API ile oyun içinde üretiliyor.

## Oynamak

`index.html` dosyasını bir tarayıcıda aç. Fare ve dokunmatik ekranla oynanır.

## Aşamalar

1. Çöp ve çamur kazıma
2. Buharlı leke eritme
3. İlaçlama ve köpürtme
4. Döner fırçalama
5. Tazyikli su ile durulama
6. Su çekme (vakum)
7. Saçak tarama
8. Parfüm ve bitiş

Temizlik kalitesine göre 1–5 yıldız ve para kazanılır. Marketten alet geliştirmeleri, köpük, parfüm ve yeni halı modelleri alınabilir. İlerleme tarayıcıda saklanır.
